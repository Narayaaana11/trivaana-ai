# TRIVAANA AI — Integrations Guide

## Supported Provider Adapters
1. **AI & Voice**: OpenAI (`OPENAI_API_KEY`), LiveKit (`LIVEKIT_URL`, `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET`), ElevenLabs (`ELEVENLABS_API_KEY`), Sarvam AI (`SARVAM_API_KEY`), IndicF5 (`INDICF5_ENDPOINT`), Faster-Whisper (`FASTER_WHISPER_ENDPOINT`).
2. **Telephony**: Exotel (`EXOTEL_*`), Twilio (`TWILIO_*`), LiveKit SIP (`LIVEKIT_SIP_CONFIG`).
3. **Business Tools**: Google Calendar & Google Sheets (`GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`), WhatsApp Cloud API (`WHATSAPP_ACCESS_TOKEN`, `WHATSAPP_PHONE_NUMBER_ID`), Razorpay (`RAZORPAY_*`).
4. **CRMs & Automation**: Zoho CRM, LeadSquared, Meta Lead Ads, Zapier, Make, Pabbly Connect, WordPress, Custom REST APIs, and HMAC-SHA256 Webhooks (`X-Trivaana-Signature`).
