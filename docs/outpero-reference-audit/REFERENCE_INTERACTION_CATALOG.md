# Outpero Reference Interaction Catalog

| Trigger / Control | Location | Observed Behaviour |
|---|---|---|
| `Search ⌘K` | Sidebar / Header | Opens global command palette to jump across sections and records |
| `Calling activity` | Top Bar | Opens popover showing live in-flight calls across Instant, Campaigns, Incoming |
| `Notifications` bell | Top Bar | Opens tabbed popover (`All`, `People`, `Updates`), `Mark all read`, low-credit warnings |
| `Theme toggle` | Top Bar | Switches light (`#ffffff`/`#f6f6f8`) and dark (`#121019`/`#0c0a12`) tokens |
| `Setup guide` | Bottom-Right | Expands/collapses 6-step onboarding checklist with direct links |
| `Templates` / Category Accordion | `#/` & `#/employees/new` | Expands industry template list (e.g., 10 BFSI templates) and populates prompt |
| `Paste it here` | `#/employees/new` | Opens `Paste a copied script` JSON modal with `Check script` validation |
| `Continue` (Prompt Builder) | `#/` & `#/employees/new` | Disabled until prompt text is entered |
| View Switcher (`Pipeline`/`List`/`Cards`/`Priority`) | `#/leads` | Switches lead rendering layout without losing active filters |
| `More filters` | `#/leads` | Expands `Credits per person` min/max and `Calls between` date inputs |
| `Lists` button | `#/campaigns` | Opens Contact Lists modal (`Reusable` vs `Suppression` lists, `New list` inline form) |
| `New campaign` | `#/campaigns` | Shows `You need a phone number first` guard modal when 0 dedicated numbers exist, offering `Continue anyway` or `Get a number` |
| `Send me a sample` | `#/settings` | Triggers sample notification email preview |
| `Pause pop-ups` (`1 hour` / `Rest of today`) | `#/settings` | Temporarily snoozes browser live-call toast notifications on current device |
| `Add credential` | `#/settings/credentials` | Opens modal to save API key / Bearer / Basic / Header secrets for AI actions |
| `Add endpoint` | `#/developers/webhooks` | Opens webhook modal with URL, `Include call transcripts` toggle, and 6 event checkboxes |
