# Outpero Reference Feature Inventory

Observed across `https://app.outpero.com/#/` and `https://outpero.com/`.

## 1. Shell, Navigation & Onboarding
- Collapsible left sidebar (`240px` expanded, `3rem` icon-only) with workspace switcher (`Order It Up`).
- Global Command Palette (`Search ⌘K`).
- Top-bar `Calling activity` live popover, `Take the tour`, `Help and docs`, Dark/Light theme toggle, and `Notifications` bell (`All`, `People`, `Updates`, `Mark all read`, low-balance alerts).
- Floating bottom-right `Ask Swara` AI guide drawer, `Support and feedback`, and 6-step `Setup guide`.

## 2. AI Employees & Prompting
- Natural-language prompt builder with Language combobox (7 Indian languages), `Natural spoken` toggle, `Describe it by voice`, `Mode` radio (`Instant`, `Bulk`, `Inbound`).
- 14-category Industry Template Browser (e.g., 10 BFSI templates with channel tags).
- `Paste a copied script` JSON import modal (`Check script`).
- Voice catalog with Standard (`₹5/min`) and Premium (`₹6.8/min`) tiers and curated personas (`P01`–`P10+`).

## 3. Calling Modes
- **Instant Leads**: Sub-30s callback SLA, sub-tabs (`Activity`, `Analytics`, `Queue`, `Sources`), connectors (Meta Lead Ads, IndiaMART, JustDial, Zoho CRM, LeadSquared, Sell.Do, Zapier, Make, n8n, Pabbly, WordPress/Wix, Google Sheets, Custom API).
- **Bulk Campaigns**: Contact Lists dialog (`Reusable` & `Suppression` lists), number-check guard modal, split Campaign Creator with CSV/XLSX upload, paste numbers, calling hours, calling days (Mon–Sun), auto-retries, pacing/concurrency, right sticky summary.
- **Incoming Calls**: Sub-tabs (`Overview`, `Calls`, `Messages`, `Missed callers`), `Who answers`, `Which number rings whom`, browser/phone test call.

## 4. Results & Intelligence
- **Leads**: 4 view modes (`Pipeline`, `List`, `Cards`, `Priority`), search, sort, export, channel/date/outcome filters, `More filters` (credits per person min/max, custom date range).
- **Conversations**: Call history, audio playback, transcripts, extracted structured key-value fields, AI summaries, action badges (WhatsApp, Google Sheets, CRM).
- **Performance**: Period & employee/channel analytics.

## 5. Workspace, Telephony, Billing, Settings & Developers
- **Numbers & Channels**: 2-step KYC & DLT number provisioning (`Mobile ₹649/mo`, `Landline ₹899/mo`), extra concurrent channels (`₹250/mo`), inbound/outbound assignment.
- **Billing**: Overview, Statement ledger, Billing details (GSTIN), Add credits (presets + custom + 18% GST).
- **Settings**: General (email alerts, sample email, live call popups with 1h/rest-of-day snooze), Account & Security, Remembered Callers, Do-Not-Call List, Credentials vault, Privacy & Data.
- **Developers**: Public lead-intake quickstart (`X-Outpero-Lead-Secret`), API keys, Webhooks (with `Include call transcripts` toggle & 6 selectable event checkboxes, HMAC-SHA256 `X-Outpero-Signature`), API Activity logs.
