- **Authentication & Multi-Tenancy**: Registration, login, JWT Bearer (plus optional OIDC), scoped revocable API keys (`api_keys`), workspace isolation, password reset & email verification token invalidation (`token_version`), team invitations & 5-role RBAC (`owner`, `admin`, `manager`, `operator`, `viewer`), and peer-admin escalation guards.
- **AI Employee Builder & Prompt Engine**: 22+ structured fields, Gemini primary / OpenAI fallback LLM generation (`LLMAdapter`) with deterministic template fallback when LLM keys are absent, version history & restore, `@xyflow/react` Visual Call Flow editor, `ACTION_CALL:` tool dispatch during conversational turns, and pre-publish Safety & Multilingual Eval Scorecard (`POST /api/voice-engine/evaluate`).
- **Voice Management & Real-Time Voice Engine**: Multi-provider voice library (`Sarvam AI`, `ElevenLabs`, `OpenAI TTS`, `IndicF5`), SHA-256 `TTSCache`, 7 Indian language targets (`en-IN`, `hi-IN`, `te-IN`, `ta-IN`, `kn-IN`, `ml-IN`, `mr-IN`), `LiveKit` room token generator & worker (`livekit_agent_worker.py` with call cost finalization), pluggable STT (`Deepgram`, `OpenAI Whisper`, `Faster-Whisper`, `IndicConformer`), real-time bidirectional PSTN WebSocket audio engine (`backend/voice_engine/telephony_stream.py` with 20ms mulaw/pcm16 framing, RMS VAD, barge-in `clear`, DTMF), signed TwiML/Exotel/Plivo/Vobiz stream tokens, warm human transfer, and latency benchmarking.
- **Four Calling Modes**:
  1. **Instant Lead Calling**: Authenticated `POST /api/public/lead-intake/{agent_slug}`, consent/DNC gates, durable DB `scheduled_calls` delayed callback queue, instant dispatch.
  2. **Bulk Calling Campaigns**: Campaign CRUD, reusable & suppression Contact Lists, weekday toggles, durable `campaign_jobs` queue, duplicate dial prevention, retry processing with agent language resolution, scheduled campaign auto-activation, TRAI calling hours & concurrency enforcement, provider circuit breakers, pause/resume/kill switch, and CSV export.
  3. **Inbound Calling**: Exotel/Twilio/Plivo/Vobiz inbound webhooks & Stream XML + after-hours transfer (`<Dial>`) + sandbox simulator.
  4. **Voice Broadcast**: Separate one-way TTS/audio announcement module with CSV recipient upload, DNC scrubbing, TRAI calling-hour enforcement, and dispatch-gated debiting.
- **Knowledge Base (RAG) & Call Intelligence**: Text/file/URL ingestion, OpenAI/local embeddings, `pgvector` schema & search, plus post-call `/analyze` using `LLMAdapter` (Gemini/OpenAI) with deterministic keyword fallback.
- **During-Call Actions & Visual Workflows**: Non-sandbox Google Calendar OAuth sync (`ActionService.sync_google_calendar_event`), Meta WhatsApp templates, Google Sheets, SSRF-hardened custom API calls (`safe_http_request`), Call Transfer `control_xml`, Caller Memory, and conditional graph traversal in `workers/workflows/temporal_worker.py` with optional Temporal server dispatch.
- **Wallet, Billing, Super Admin & Staff Portals**: Integer paise append-only ledger, 18% GST SAC 998313 calculation & invoices, Razorpay checkout/webhook HMAC + `httpx` verification, provider COGS & gross margin accounting (`/api/admin/finance/summary`), global emergency kill switch, audited read-only staff tenant summaries, validated staff KYC & ticket triage, and encrypted tenant credential storage (`core/vault.py`).
- **Deployment & Infrastructure**: `.env.example`, Dockerfiles, `docker-compose.yml` (PostgreSQL+pgvector, Redis, Backend, Worker, Voice Engine, Frontend/Nginx), and `infrastructure/terraform/` AWS ECS/S3/SQS/Secrets Manager starter templates.
